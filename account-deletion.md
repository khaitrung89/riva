# RIVA Account and Data Deletion

App name: RIVA

Package name: `com.ourtour24h.app`

RIVA users can request deletion of their account and associated app data by contacting support through this public support channel:

https://github.com/khaitrung89/riva/issues

## How to request deletion

1. Open the support link above.
2. Create a new issue with the title `Account deletion request`.
3. Include the Google account email used to sign in to RIVA.
4. Do not include passwords, private documents, payment card details, or other sensitive information.

If GitHub Issues are not available, users can contact the developer email shown on the Google Play listing and include the same request details.

## Data deleted

After verifying that the request belongs to the correct user account, RIVA will delete or anonymize account-scoped data where technically possible, including:

- Profile information linked to the user account.
- Trip records, members, expenses, transfers, and sync records linked to the user account.
- User-created videos, thumbnails, livestream replay records, comments, reactions, shares, and related engagement records linked to the user account.

## Data that may remain

Some data may remain for a limited time when required for security, legal compliance, abuse prevention, backup recovery, debugging, or platform operation. Local device data can also be removed by clearing app data or uninstalling RIVA from the Android device.

Deletion requests are normally reviewed within 30 days after account ownership is verified.
